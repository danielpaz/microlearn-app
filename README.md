# App Microlearn — app.microlearn.website

Os mesmos arquivos autocontidos do Microlearn (www.microlearn.website, Google Sites), publicados com endereço fixo para o app do Google Workspace Marketplace: login com Google, prova certificada e, depois, certificado e compra.

- `/` portal · `/<plataforma>/` cada plataforma (`ai2`, `git`, `sql`…)
- Plataformas que ainda não estão aqui (`py`, `stats`, `phys`, `chem`) abrem no site público pelo `404.html`.
- `robots.txt` bloqueia buscadores: o site público é o que aparece no Google.
- Padrão: `micro-padrao-certificado.md` (projeto .Micro).
